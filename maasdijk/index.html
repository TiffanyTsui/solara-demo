Maasdijk

Three greenhouses, one physical model each, built from the measured buildings and the settings the grower runs. The model was calibrated at Made and moved here without refitting. It reconstructed the indoor climate from 5 January to 3 September 2026 on observed weather. The measured weeks score it afterwards; they never feed it.

The three greenhouses

How to read this page

  • One model per greenhouse. Inside a greenhouse the compartments differ from each other by about 0,6 °C in daily mean. The model cannot see that difference, so an error of that size is the floor for any model that sits outside the compartment.
  • The line is the model, the dots are the sensor. The model runs every hour of the eight months. A dot appears only on days an export exists for that compartment.
  • The daily maximum runs 2–3 °C cold. The model reaches the afternoon peak late. The same shortfall exists at Made and is where the next calibration round goes. Daily means carry the score; the maxima are in the day tables under each chart, so the shortfall stays visible.
  • Heating and venting are one setting all year. The grower raises both for some weeks after a planting. Those weeks read cold in the model, in whichever compartment was just planted.
  • Weather is KNMI Rotterdam, 17 km away. Hoek van Holland is nearer but publishes no cloud cover, which the model needs.
  • Kas 2 and Kas 3 are the two halves of one building, split along the central path. Which half holds afdeling 5–7 is not recorded; the model does not depend on it.
  • No forecast on this page. The Made page forecasts 48 hours ahead every morning. The same run can be switched on for Maasdijk.
  • Where the numbers live. Every figure here is written from the model repository by one script. Corrections go there first; this page follows.
